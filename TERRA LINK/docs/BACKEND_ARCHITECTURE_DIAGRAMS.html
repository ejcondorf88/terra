🎯 Visión General del Backend

TERRA LINK Backend es una aplicación NestJS modular que expone un conjunto de APIs REST para gestionar compliance, créditos, facturación, tenants y validaciones geoespaciales. Utiliza TypeORM para persistencia con PostgreSQL y RBAC (Role-Based Access Control) para securizar endpoints según roles de usuario.

🔧 Stack Tecnológico

Framework: NestJS v10
ORM: TypeORM
BD: PostgreSQL
Auth: JWT + RBAC Guards

📦 Módulos Principales

10 módulos independientes + Compliance con subcontroladores especializados

🔐 Seguridad

Global: TenantMiddleware
Guards: JwtAuthGuard + RbacGuard
Validación: Por endpoint

🔗 Integraciones

Trace, GUI, MAG, Satellite APIs
Stripe Webhooks
Smart Contracts

Etapas del Pipeline

1️⃣ TenantMiddleware

Se aplica globalmente. Extrae tenant_id del header o contexto y lo inyecta en el request.

2️⃣ JwtAuthGuard

Valida que el JWT token sea válido y no esté expirado. Rechaza con 401 si falla.

3️⃣ RbacGuard

Verifica que el usuario tiene el rol requerido para el endpoint. Rechaza con 403 si no.

4️⃣ Controller

Recibe DTO validado. Delega lógica al Service.

5️⃣ Service

Ejecuta lógica de negocio. Accede a repositorios TypeORM y adaptadores externos.

6️⃣ Response

Servicio retorna resultado. Controller mapea a DTO y devuelve al cliente.

🔗 Patrones de Integración

El backend se integra con múltiples sistemas externos a través de adaptadores especializados. Estos patrones aseguran desacoplamiento y facilidad de mantenimiento.

1. Patrón Adapter para APIs Externas

Trace API Adapter

TraceAdapter encapsula la comunicación con el sistema de trazabilidad. ComplianceService lo utiliza para validar y registrar cadena de suministro.

Satellite API Adapter

SatelliteAdapterService consulta imágenes satelitales para validar parcelas. SatelliteValidationService procesa los datos y almacena validaciones en BD.

2. Patrón Repository para Persistencia

TypeORM Repositories

Cada entidad (Certification, EudrRegistry, EsgReport, etc.) tiene su repositorio inyectado vía TypeOrmModule.forFeature().

Entity Relationships

Las entidades definen relaciones OneToMany, ManyToOne para mantener integridad referencial.

3. Guardias y Middleware

TenantMiddleware

Aplicación: Global
Función: Inyecta tenant_id en request context
Propósito: Garantizar multi-tenancy

JwtAuthGuard

Aplicación: Selectiva por módulo
Función: Valida JWT token
Propósito: Autenticación segura

RbacGuard

Aplicación: Selectiva por endpoint
Función: Valida roles (@Roles decorator)
Propósito: Control de acceso basado en roles

4. Inyección de Dependencias

NestJS Dependency Injection Container

Todos los servicios, adapters y repositorios se inyectan automáticamente en controladores mediante decoradores @Injectable() y constructor parameters. Esto permite:

  • ✓ Desacoplamiento de componentes
  • ✓ Facilidad para testing con mocks
  • ✓ Escalabilidad y mantenimiento
  • ✓ Reutilización de servicios entre módulos

5. Flujo Típico de una Petición Compliance

Ejemplo: POST /compliance/certifications

1. Cliente envía POST con CreateCertificationDto
2. TenantMiddleware inyecta tenant_id
3. JwtAuthGuard valida token
4. RbacGuard valida rol (admin | exportador)
5. ComplianceController.createCertification() recibe DTO
6. ComplianceService.createCertification() ejecuta lógica:
    - Consulta GUI/MAG adapters si es necesario
    - Persiste Certification entity en BD
    - Retorna CertificationDto
7. Controller retorna response 201 Created al cliente

📖 Apéndice: Glosario Técnico

RBAC

Role-Based Access Control. Sistema de control de acceso basado en roles de usuario.

DTO

Data Transfer Object. Objeto que encapsula datos para transferencia entre capas/servicios.

Repository Pattern

Patrón que abstrae el acceso a datos. TypeORM proporciona repositories automáticos.

Adapter Pattern

Patrón que encapsula integración con sistemas externos para desacoplamiento.

Guard

Middleware en NestJS que ejecuta lógica antes de llegar al handler (auth, roles, etc).

Middleware

Función ejecutada antes de que la petición llegue al controlador. Global o selectiva.

Service

Clase que contiene lógica de negocio y es reutilizable entre controladores.

Tenant

Aislamiento lógico de datos/usuarios en sistema multi-tenant. Clave para seguridad.

EUDR

European Union Deforestation Regulation. Normativa para trazabilidad de productos.

ESG

Environmental, Social, Governance. Criterios de sostenibilidad empresarial.
