# Shared Package

Este paquete contiene utilidades, tipos y lógica compartida que pueden reutilizarse en los proyectos de `TERRA GO`, `TERRA LINK` y `TERRA X CHANGE`.

## Objetivo

- Reducir duplicación de código.
- Compartir modelos de datos, validaciones y adaptadores comunes.
- Facilitar la migración de funcionalidades repetidas a un solo lugar.

## Uso

Desde cualquier paquete del workspace, importa usando:

```ts
import { example } from '@terra/shared'
```
